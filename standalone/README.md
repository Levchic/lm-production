# Автономный калькулятор

`Калькулятор-стоимости.html` — один файл, внутри которого всё: разметка,
стили, шрифты и логика расчёта. Ни одного обращения в сеть. Открывается
двойным кликом, работает офлайн, пересылается как обычное вложение.

## Сборка

```
npm run build:calc
```

Собирает **две** версии одного и того же калькулятора:

| Файл | Для чего |
|---|---|
| `Калькулятор-стоимости.html` | самодостаточный файл: открыть с диска, работать офлайн |
| `artifact-page.html` | тот же контент без `<!doctype>`, `<html>`, `<head>` и `<body>` — заготовка для публикации ссылкой (страницу-артефакт заворачивают в свой скелет) |

Обе — из одних и тех же источников:

| Источник | Что берётся |
|---|---|
| `js/pricing-config.js` | прайс целиком, дословно |
| `js/pricing-overrides.js` | правки прайса из админки, дословно |
| `js/pricing-calc.js` | расчёт, дословно |
| `js/pricing-schema.js` | список полей редактора, дословно |
| `js/pricing-ui.js` | форма и смета, дословно |
| `css/styles.css` | блок токенов `:root` и блок стилей калькулятора |
| `assets/fonts/*.woff2` | Unbounded и Jost, вшиваются в base64 |
| `standalone/shell.html`, `app.css`, `app.js` | оболочка: шапка, редактор прайса |

**Логика не дублируется.** Сайт и автономная версия считают одним и тем же
кодом, поэтому после пересмотра цен достаточно пересобрать файл — разойтись
они не могут. Единственное, чем `pricing-ui.js` цепляется за сайт, —
`window.SiteCommon` (экранирование и язык); в `app.js` для него стоит
трёхстрочная заглушка.

## Полоса с итогом на узких экранах

До 980 px смета не помещается рядом с формой и уезжает под неё. Чтобы
цифра всё равно оставалась на виду, снизу липнет полоса высотой 45 px с
одним итогом; по нажатию она прокручивает к разбору и прячется, когда
смета показалась на экране. На широких экранах полосы нет — там смета
висит рядом.

Видимость считается на событии прокрутки, а не через
`IntersectionObserver` и не через `requestAnimationFrame`: и то и другое
молчит, пока документ не композитится (фоновая вкладка, свёрнутая панель
предпросмотра), и полоса тогда не появляется вовсе — отказ тихий.

## Что умеет оболочка

- **Для себя / Для клиента** — точные суммы со ставками против вилки без ставок.
- **Настроить прайс** — 180 с лишним полей: ставки этапов, надбавки, скидки,
  сдача комплекта и приёмка проекта, ступени прав и надбавки к ним, налог и
  договорная надбавка, названия и границы категорий, тексты вопросов и баллы
  вариантов, типы работы, коэффициенты, вилка. Изменённые поля подсвечены.
  Какие именно поля показывать, решает `js/pricing-schema.js` — тот же файл
  рисует редактор прайса в админке сайта, поэтому списки не расходятся.
- **Весь прайс в JSON** — для структурных правок: добавить этап, тип работы
  или вопрос.
- **Сохранить в файл / Загрузить из файла** — перенос своего прайса на другое
  устройство или передача коллеге.
- **Сбросить** — возврат к исходному прайсу.

## Где живут правки

Отсчёт идёт не от чистого `pricing-config.js`, а от того, по чему сайт
считает сегодня: правки из админки (`js/pricing-overrides.js`) вшиваются
в файл при сборке. Поэтому «Сбросить» возвращает к ценам сайта, а не к
тем, что записаны в коде.

Свои правки поверх этого живут в `localStorage` того браузера, где открыт файл. Хранятся точечно —
«путь → значение», поэтому пересборка калькулятора с новыми полями правки
не ломает. Правка JSON целиком сохраняет прайс полностью и этот механизм
отключает; «Сбросить» возвращает всё обратно.

## Открытие файла напрямую: важно

Chrome не даёт странице, открытой как `file://`, писать в `localStorage` —
правки прайса живут до закрытия вкладки. Страница это определяет и
показывает предупреждение с подсказкой сохранить прайс в файл.

Где всё запоминается само:

- **Safari и Firefox** — при открытии файла напрямую;
- **любой браузер** — если файл открыт по ссылке (`http://` или `https://`),
  например с локального сервера или из облака.

## Передача

Файл весит около 300 КБ. Telegram, почта и облачные диски принимают его как
обычное вложение. Получателю достаточно открыть — установка не нужна, свои
цены он проставит в «Настроить прайс».

### Ссылкой, а не файлом

**iOS локальные HTML-файлы не открывает.** «Файлы» показывают статичное
превью, Safari такой файл не берёт, и «Открыть с помощью» ничего не
предлагает. Это ограничение системы, а не калькулятора: на iPhone нужна
ссылка.

Ссылка сделана публикацией `artifact-page.html` — страница живёт по адресу
вида `claude.ai/code/artifact/<id>`, приватна, пока владелец не поделится.
Открывается на любом телефоне, настройки у каждого зрителя свои.

Что в версии по ссылке работает иначе:

- **страница живёт в рамке**, поэтому скачать файл она не может — браузер
  гасит такую попытку молча. Код это определяет заранее (`canDownload`) и
  вместо файла кладёт прайс в буфер обмена и показывает его в поле
  «Весь прайс в JSON»; кнопка честно называется «Скопировать прайс»;
- **системные диалоги недоступны**, поэтому сброс подтверждается вторым
  нажатием той же кнопки, а сообщения выводятся строкой под шапкой,
  а не через `alert()`;
- **тёмная схема объявлена через `:root`**: обёртка страницы-артефакта
  ставит `:root{color-scheme:light}`, и селектор `html` ей проигрывает
  по специфичности.

Обновить опубликованную страницу — пересобрать и опубликовать
`artifact-page.html` по тому же адресу.
